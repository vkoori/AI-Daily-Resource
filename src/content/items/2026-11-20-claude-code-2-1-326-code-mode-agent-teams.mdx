## این موضوع چیست و چرا الان مطرح شده؟

«Code Mode» در Claude Code به Agent اجازه می‌دهد به‌جای ارسال یک پیام
جدا برای هر فراخوانی ابزار، چند ابزار را در قالب یک قطعه کد جاوااسکریپت
پشت‌سرهم صدا بزند — روشی که معمولاً سریع‌تر و کم‌هزینه‌تر از رفت‌وبرگشت
پیام‌به‌پیام است. تا پیش از نسخهٔ ۲.۱.۳۲۶، این حالت با «Agent Teams»
(ویژگی‌ای که چند Agent هم‌زمان در یک نشست با هم کار می‌کنند) سازگار نبود؛
طبق مستندات، تلاش برای فعال کردن هم‌زمان این دو، با پیام خطای «Code Mode
(experimental) isn't available» و دلیل «هنوز نمی‌تواند با Agent Teams
استفاده شود» مواجه می‌شد. نسخهٔ منتشرشده در ۱۶ نوامبر ۲۰۲۶ همین محدودیت
را برمی‌دارد: اکنون می‌توان Code Mode را درحالی‌که Agent Teams فعال است
روشن کرد، و نشست‌هایی که از قبل Team فعال داشته‌اند، مستقیماً با Code
Mode شروع می‌شوند.

## چه زمانی این موضوع به کارتان می‌آید؟

اگر تیمی هستید که از Agent Teams در Claude Code برای تقسیم یک وظیفهٔ
بزرگ بین چند Agent هم‌کار استفاده می‌کنید و تا امروز نمی‌توانستید
Code Mode را هم‌زمان با آن روشن کنید، این نسخه مستقیماً به شما مربوط
است. اگر هم روی قوانین Allow مبتنی بر Wildcard در تنظیمات Auto Mode یا
محیط Sandbox خودتان حساب باز کرده‌اید — به‌خصوص قاعده‌هایی که با $HOME
شروع می‌شوند — پیش از ارتقا به این نسخه، تنظیمات خود را بازبینی کنید، چون
ممکن است دیگر به همان شکل قبلی به‌طور خودکار تأیید نشوند.
