## این موضوع چیست و چرا الان مطرح شده؟

Agent Skills یک استاندارد باز برای بسته‌بندی دانش رویه‌ای و گردش‌کار
تخصصی است که یک Agent (مثل Claude Code) می‌تواند هنگام نیاز بار کند:
یک پوشه با فایل `SKILL.md` در مرکز آن، به همراه هر اسکریپت یا منبع
مرجعی که آن وظیفهٔ خاص لازم دارد. Anthropic این الگو را در حین کار
روی Claude Code برای حل یک مشکل مشخص توسعه داد: کارهای واقعی کسب‌وکار
اغلب به دانش رویه‌ای (نه فقط دستورالعمل کلی) نیاز دارند که نمی‌شود هر
بار آن را از صفر در Prompt نوشت. این استاندارد در اکتبر ۲۰۲۵ معرفی و
در دسامبر ۲۰۲۵ به‌صورت رسمی به‌عنوان یک استاندارد باز منتشر شد. نکتهٔ
تازهٔ ۲۲ اکتبر ۲۰۲۶، اهدای کامل آن — نام و لوگوی Agent Skills، سازمان
GitHub آن، دامنهٔ agentskills.io و خودِ استاندارد — به Agentic AI
Foundation (AAIF) است؛ بنیادی زیرمجموعهٔ Linux Foundation که Anthropic
آن را به همراه Block و OpenAI تأسیس کرده و پیش‌تر میزبان اهدای
Model Context Protocol (MCP) هم بوده است.

## چه مشکلی را حل می‌کند و چگونه کار می‌کند؟

قبل از Skills، دو راه رایج برای دادن دانش تخصصی به یک Agent وجود
داشت: یا همه‌چیز را در System Prompt بنویسیم (که هر بار بارگذاری
می‌شود، حتی اگر لازم نباشد) یا یک ابزار/MCP Server بسازیم (که برای
دانش رویه‌ای صرف، سربار مهندسی زیادی دارد). Skill راه سومی است: یک
پوشهٔ ساده با `SKILL.md` که شرح می‌دهد این دانش چه زمانی مرتبط است،
و Agent فقط وقتی به آن نیاز دارد آن را بار می‌کند — نه همیشه. این
سبک‌وزن‌بودن، همراه با سازگاری با چندین پلتفرم مختلف، دلیل اصلی رشد
سریع پذیرش آن است.

## چه زمانی و برای چه کسی اهمیت دارد؟

برای تیم‌هایی که همین حالا روی Claude Code، ChatGPT، Cursor، GitHub
Copilot یا VS Code از Skill استفاده می‌کنند، این خبر یعنی استانداردی
که به آن تکیه کرده‌اند دیگر صرفاً زیر کنترل یک فروشنده نیست — ریسک
تغییر یک‌طرفهٔ قوانین بازی کمتر می‌شود. برای مهندسانی که می‌خواهند
برای اولین‌بار Skill بنویسند یا روی چند پلتفرم Agent مختلف قابل‌حمل
نگهش دارند، وجود فرایند پیشنهاد رسمی و انتشار نسخه‌بندی‌شده یعنی
می‌توانند انتظار پایداری بیشتری از مشخصات داشته باشند. برای کسانی که
در حال ارزیابی «Skill بسازم یا MCP Server؟» هستند، این خبر یادآوری
می‌کند که هر دو مسیر اکنون زیر یک سقف حاکمیتی مشترک (AAIF) قرار
دارند، نه دو استاندارد رقیب با آینده‌های جداگانه.

## مقایسه با مسیر MCP

این دومین‌بار است که Anthropic یک استاندارد Agent را به AAIF اهدا
می‌کند — پیش از این، Model Context Protocol (برای اتصال Agentها به
ابزارها و منابع داده بیرونی) همین مسیر را طی کرده بود. Anthropic در
پست خود صراحتاً می‌گوید قصد دارد همان الگوی «اولویت به ورودی جامعه و
شفافیت در تصمیم‌گیری» که برای MCP اجرا شده را برای Skills هم تکرار
کند. تفاوت کاربردی این دو: MCP دربارهٔ *اتصال* Agent به دنیای بیرون
است (ابزار، دیتابیس، API)، درحالی‌که Skill دربارهٔ *دانش رویه‌ای*
داخلی خودِ Agent برای انجام یک وظیفه است — دو لایهٔ مکمل، نه رقیب، در
معماری یک Agent امروزی.
