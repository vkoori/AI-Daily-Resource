  جمع‌بندی رسمی OpenAI از بیش از ۲۰ اعلامیه DevDay 2026، با تمرکز بر ابزارهای
  توسعه‌دهنده: (۱) Codex اکنون در محیط ابری هم اجرا می‌شود — می‌توان از گوشی یا
  مرورگر یک کار را شروع کرد و محیط توسعه Reusable در ابر آن را اجرا کند؛ (۲)
  Codex CLI بازطراحی شده: ورودی صوتی برای تعریف وظیفه و یک نمای جدید `/agents`
  برای پیگیری و واگذاری چند وظیفه هم‌زمان؛ (۳) ابزار Code Review در دسکتاپ
  ChatGPT برای بررسی Diff، خلاصه تغییرات و بازخورد روی PRهای GitHub/GitLab، با
  امکان اجرای خودکار در ابر؛ (۴) Codex Security Cloud برای اسکن زمان‌بندی‌شده
  یا درخواستی مخازن، بررسی یافته‌ها و آماده‌سازی خودکار Patch؛ (۵) Agents API
  با قابلیت Computer Use (کار با رابط گرافیکی برنامه‌ها)، به‌علاوه چند-Agent،
  جست‌وجوی ابزار، Tool Calling و Context Compaction که زیرساخت اجرای آن را خود
  OpenAI مدیریت می‌کند؛ (۶) Decisions API (پیش‌نمایش محدود) که از مدل کوچک Luna
  برای انتخاب یک گزینه از میان مجموعه‌ای از پاسخ‌های از پیش تعریف‌شده استفاده
  می‌کند، مناسب برای دسته‌بندی و مسیریابی. نکته عملی برای تیم‌های Vibe Coding:
  مرز بین «دستیار کدنویسی محلی» و «Agent ابری با محیط اجرای کامل و اسکن امنیتی
  خودکار» دارد کمرنگ می‌شود؛ تیم‌هایی که از Codex/Copilot استفاده می‌کنند بهتر
  است گردش‌کار بازبینی PR و اسکن امنیتی را از همین الان حول این ابزارهای ابری
  طراحی کنند، نه صرفاً تولید کد.
