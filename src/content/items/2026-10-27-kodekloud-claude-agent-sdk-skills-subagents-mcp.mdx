## این موضوع چیست و چرا الان مهم است؟

بسیاری از تیم‌هایی که برای اولین‌بار با Claude Agent SDK (کیت رسمی
Python از Anthropic برای ساخت عامل‌هایی که استدلال می‌کنند، از ابزار
استفاده می‌کنند و وظیفه را خودکار می‌کنند) کار می‌کنند، مرز بین سه
مفهوم Tool، Skill و Subagent را گم می‌کنند. دورهٔ «Learn by Doing:
Building AI Agents with Claude Agent SDK» از KodeKloud، به تدریس Sai
Krishna Yerramsetty (معمار اصلی پلتفرم در KodeKloud)، این سه مفهوم را
نه با توضیح انتزاعی، بلکه با Labهای واقعی روی AWS و Terraform —
نوشتن/اصلاح Template، رفع‌اشکال زیرساخت شکسته، و فراهم‌کردن VPC —
تمرین می‌دهد.

## چه زمانی و برای چه کسی کاربرد دارد؟

این دوره برای توسعه‌دهندگان Python‌ای که می‌خواهند از صفر با Claude
Agent SDK عامل بسازند و به‌طور خاص روی زیرساخت ابری (AWS/Terraform)
کار می‌کنند، مناسب‌ترین است. اما ارزش اصلی آن برای هر مهندسی که با
Claude Code یا SDKهای مشابه کار می‌کند، فراتر از محتوای AWS است:
تمایز عملیِ Tool در برابر Skill در برابر Subagent — که همان سؤال رایج
«این را Skill بسازم یا Subagent؟» را پاسخ می‌دهد — و الگوی اصل کمترین
دسترسی برای هر Subagent، نکته‌ای است که در هر پروژهٔ Agentic، نه فقط
زیرساخت ابری، کاربرد دارد.
