## این موضوع چیست و چرا الان مطرح شده؟

گیت‌هاب هر هفته یک پست «Weekly Releases» برای Copilot منتشر می‌کند که
تغییرات انباشته‌شده در مدل‌های در دسترس، اپ دسکتاپ/موبایل Copilot، و افزونهٔ
VS Code را یک‌جا جمع می‌کند. نسخهٔ منتشرشده در ۱۶ نوامبر ۲۰۲۶، تغییرات هفتهٔ
منتهی به ۹ نوامبر را پوشش می‌دهد و از نظر حجم و تنوع، یکی از پرمحتواترین
نسخه‌های این مجموعه در ماه‌های اخیر است — هم مدل‌های تازه اضافه شده‌اند، هم
چند قابلیت کاربردی روزمره برای توسعه‌دهنده‌ها، و هم یک تغییر معماری مهم
(کنار گذاشتن Local Harness) اعلام شده که روی همهٔ کاربران فعلی اثر می‌گذارد.

## چه چیزهایی تغییر کرده؟

<Callout type="fact" title="مدل‌ها و دسترسی سازمانی">
  Claude Fable ۵.۲ برای کاربران پلن‌های Pro+، Max، Business و Enterprise در
  دسترس شده است، با این نکتهٔ مهم که به‌طور پیش‌فرض نیازمند «نگه‌داری داده»
  (Data Retention) است و مدیران Business/Enterprise باید پیش از استفادهٔ
  کاربران، این سیاست را که پیش‌فرض آن خاموش است، فعال کنند. Gemini ۴ Carbon
  هم برای همان گروه از کاربران در دسترس قرار گرفته. این یعنی تیم‌هایی که
  سیاست‌های سخت‌گیرانهٔ نگهداری داده دارند باید پیش از فعال‌سازی، با بخش
  امنیت/حریم‌خصوصی سازمان هماهنگ شوند.
</Callout>

در اپ Copilot (دسکتاپ/موبایل) چند قابلیت کاربردی اضافه شده: منوی «Open in»
حالا گزینهٔ GitHub Mobile دارد که با نشان‌دادن یک QR Code، امکان ادامهٔ یک
نشست Cloud یا Codespace روی موبایل را فراهم می‌کند؛ وقتی یک سرور MCP (مثل
Slack) نیاز به ورود مجدد دارد، Copilot همان‌جا در دل مکالمه گزینهٔ اتصال را
نشان می‌دهد تا بدون قطع روند کار، دوباره وصل شوید؛ و پشتیبانی از GitHub
Enterprise Server (مخازن، Issueها و Pull Requestها) حالا به‌طور عمومی در
دسترس است (با این محدودیت که هنوز به یک حساب GitHub.com یا GHE.com نیاز
دارید و نشست‌های Cloud برای GHES در دسترس نیست).

<Callout type="caution" title="بازنشستگی Local Harness — فوریهٔ ۲۰۲۷">
  مهم‌ترین نکتهٔ این نسخه برای تیم‌های مهندسی، نه یک قابلیت جدید، بلکه یک
  حذف برنامه‌ریزی‌شده است: Local Harness در فوریهٔ ۲۰۲۷ کاملاً حذف می‌شود.
  Copilot Harness از پیش برای نشست‌های جدید پیش‌فرض شده، و گیت‌هاب یک
  «راهنمای انتقال» منتشر کرده تا جریان‌های کاری باقی‌مانده را پیش از موعد
  حذف، منتقل کنید. اگر پایپ‌لاین CI یا اسکریپت‌های تیم شما مستقیماً به رفتار
  Local Harness وابسته‌اند، همین الان زمان مناسبی برای برنامه‌ریزی مهاجرت
  است، نه بعد از رسیدن به ضرب‌الاجل.
</Callout>

## چرا این موضوع به کارتان می‌آید؟

اگر تیم شما از GitHub Copilot (خصوصاً در VS Code یا اپ Copilot) استفاده
می‌کند، این‌ها تغییراتی هستند که مستقیماً روی تجربهٔ روزمرهٔ توسعه اثر
می‌گذارند: دسترسی به مدل‌های تازه (با ملاحظات حریم خصوصی)، ابزارهای بهتر
برای مدیریت چند نشست Agent هم‌زمان، و از همه مهم‌تر، یک مهلت قطعی برای ترک
Local Harness که نادیده گرفتنش می‌تواند در فوریهٔ ۲۰۲۷ باعث اختلال در
جریان‌های کاری فعلی شود. پیشنهاد عملی: همین الان یکی از نشست‌های آزمایشی را
با Copilot Harness اجرا کنید تا هر ناسازگاری احتمالی را زودتر از ضرب‌الاجل
کشف کنید.
