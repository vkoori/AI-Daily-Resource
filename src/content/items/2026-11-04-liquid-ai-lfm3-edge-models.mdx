## این موضوع چیست و چرا الان مطرح شده؟

بیشتر مدل‌های زبانی قدرتمند امروز برای اجرا روی GPUهای قدرتمند در مرکز
داده طراحی شده‌اند، نه روی یک گوشی یا لپ‌تاپ معمولی. این یعنی هر
Agentی که روی این مدل‌ها بنا شود، به اتصال اینترنت و هزینهٔ API وابسته
است. Liquid AI در ۲۰ اکتبر ۲۰۲۶ خانواده مدل‌های LFM3 را معرفی کرد — شامل
نسخه‌های پایه، متنی، تصویری (Vision)، صوتی، Omni و تصمیم‌گیری — که
هدف‌شان دقیقاً حل این مشکل است: اجرای کامل Agentهای Tool-Calling روی
دستگاه خودِ کاربر، بدون نیاز به سرور ابری.

## چگونه کار می‌کند؟

ترکیب معماری LFM3 — به‌جای تکیهٔ کامل بر Transformer استاندارد — از سه
نوع لایهٔ متفاوت استفاده می‌کند: اکثر لایه‌ها (۱۳ از ۲۴) از نوع
Convolution کوتاهِ Gate-دار هستند که سریع‌تر و کم‌حافظه‌تر از توجه کامل
عمل می‌کنند؛ تعداد کمتری لایهٔ توجه پنجره‌ای (Sliding-Window) و توجه
سراسری (Global Attention) هم برای حفظ توانایی درک کانتکست طولانی اضافه
شده‌اند. این مدل به‌طور خاص برای کار با Harnessهای Agent (مانند Hermes
Agent، Pi و OpenClaw) Post-train شده و از Tool Calling ساختاریافته و
Deferred Tool Search (جست‌وجوی ابزار با تأخیر، برای کاهش بار کانتکست)
پشتیبانی می‌کند. فرمت‌های خروجی شامل BF16، FP8، NVFP4، GGUF، MLX و ONNX
است — یعنی روی سخت‌افزارهای مختلف (از iPhone تا لپ‌تاپ‌های معمولی) قابل
اجراست.

## چه زمانی و برای چه کسی کاربرد دارد؟

این دسته از مدل‌ها برای تیم‌هایی مناسب است که می‌خواهند یک Agent سادهٔ
Tool-Calling (مثلاً یک دستیار محلی برای خودکارسازی کارهای روی دستگاه،
یا یک Agent که باید بدون اتصال دائمی به اینترنت کار کند) بسازند و
هزینه/تأخیر فراخوانی API ابری برایشان مهم است. برای کارهای نیازمند دانش
عمومی وسیع، استدلال پیچیدهٔ چندمرحله‌ای یا کدنویسی Agentic سطح بالا،
خودِ Liquid AI صراحتاً استفاده از این مدل را توصیه نمی‌کند.

## مقایسه با گزینه‌های مشابه

LFM3-1.7B در همان دسته‌ای قرار می‌گیرد که مدل‌های کوچک متمرکز بر Edge
مانند خانواده‌های Phi از مایکروسافت یا نسخه‌های کوچک Gemma از گوگل قرار
دارند — همه با هدف اجرای محلی و کم‌حافظه. نقطهٔ تمایز اصلی LFM3 معماری
سه‌گونه‌ترکیبی (به‌جای Transformer خالص) و تمرکز صریح روی Post-training
برای Harnessهای Agent است، نه صرفاً چت عمومی. اما چون منابع موجود در
این اجرا عدد بنچمارک مقایسه‌ای ارائه نمی‌دهند، این مطلب نمی‌تواند ادعا
کند LFM3 از نظر کیفیت خام از رقبای هم‌رده بهتر یا ضعیف‌تر است — فقط
تفاوت در هدف طراحی و معماری را می‌تواند با اطمینان گزارش کند.
