<Callout type="analysis">
  نکته‌ای که ارزش توجه دارد: OpenAI در Agents API صراحتاً می‌گوید «زیرساخت
  اجرا را خودمان مدیریت می‌کنیم» — یعنی مسئولیت بخشی از Infra (که قبلاً
  وظیفه تیم مهندسی مشتری بود) به سمت OpenAI منتقل می‌شود. این برای تیم‌های
  کوچک‌تر می‌تواند ساده‌کننده باشد، اما به معنای وابستگی بیشتر به زیرساخت
  یک فروشنده خاص هم هست — یک Trade-off که باید آگاهانه ارزیابی شود.
</Callout>

## چرا این برای تیم‌های Vibe Coding مهم است

<Callout type="tip">
  مرز بین «دستیار کدنویسی محلی روی لپ‌تاپ شما» و «Agent ابری با محیط اجرای
  کامل و اسکن امنیتی خودکار» دارد کمرنگ می‌شود. اگر تیم شما از Codex یا
  ابزار مشابه (مثل GitHub Copilot) استفاده می‌کند، توصیه عملی این است که
  از همین الان گردش‌کار بازبینی PR و اسکن امنیتی را حول همین قابلیت‌های
  ابری طراحی کنید — نه این‌که فرض کنید تولید کد و بازبینی امنیتی دو فرایند
  کاملاً جدا و دستی باقی می‌مانند.
</Callout>
