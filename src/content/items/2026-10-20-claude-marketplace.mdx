## این موضوع چیست و چرا مطرح شده؟

تا پیش از این، اگر یک تیم می‌خواست ببیند چه ابزارهایی با Claude کار
می‌کنند — یک Connector برای Notion، یک Agent آماده برای تحلیل قرارداد
حقوقی، یا یک شرکت مشاوره برای کمک به استقرار سازمانی — باید در منابع پراکنده
جست‌وجو می‌کرد. **Claude Marketplace** این سه نوع نیاز متفاوت را در یک
محل جمع می‌کند. اهمیت آن برای توسعه‌دهندگان این است که مسیر رسمی و واحدی
برای عرضه ابزار خودشان به کاربران موجود Claude فراهم می‌کند، و برای تیم‌های
فنی این است که پیدا کردن و امتحان کردن ابزارهای آماده را ساده‌تر می‌کند.

## چرا به‌عنوان محتوای «مرجع» (نه خبر تازه) ثبت شده؟

این مطلب نزدیک به یک ماه پس از تاریخ انتشار اصلی (۲۳ سپتامبر ۲۰۲۶) نوشته
می‌شود، چون تا امروز در آرشیو این مجموعه پوشش داده نشده بود. با این حال،
چون این یک زیرساخت پایدار و درحال‌رشد اکوسیستم است — نه یک خبر گذرا — همچنان
برای توسعه‌دهندگانی که می‌خواهند Plugin یا Connector بسازند، یا تیم‌هایی که
دنبال ابزار آماده برای Claude هستند، ارزش مرجع دارد.

## چه زمانی باید سراغ آن بروید؟

اگر در حال ساخت یک Connector یا Plugin با MCP یا Agent Skills هستید و
می‌خواهید آن را به کاربران فعلی Claude معرفی کنید، Claude Marketplace مسیر
رسمی توزیع است. اگر به‌عنوان یک تیم مهندسی دنبال ابزار آماده (نه ساخت از
صفر) برای یک وظیفه خاص هستید — مثل ادغام با Salesforce یا یک Agent امنیتی
آماده — این مارکت‌پلیس نقطه شروع منطقی برای جست‌وجو است، پیش از آنکه یک راه‌حل
داخلی از صفر بسازید.
