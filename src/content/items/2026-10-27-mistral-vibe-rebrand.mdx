## این موضوع چیست و چرا الان مهم است؟

تا پیش از ۲۸ مه ۲۰۲۶، Le Chat دستیار گفتگوی عمومی Mistral بود و
«Vibe» فقط نام ابزار کدنویسی آن. Mistral در این تاریخ این دو را زیر
یک نام و یک اشتراک واحد ادغام کرد: از این پس همه‌چیز Vibe نام دارد،
مکالمه‌ها و تنظیمات قبلی کاربران منتقل می‌شوند، و حالت چت ساده
(Classic Chat) به‌تدریج کنار گذاشته و تاریخچهٔ آن به Work Mode منتقل
می‌شود. این تغییر در بستر رقابت مستقیم با عامل‌های کاری OpenAI، Google
و Anthropic معنا پیدا می‌کند — Mistral دیگر می‌خواهد Vibe را نه فقط
یک چت‌بات، بلکه یک عامل اجراکننده برای کار روزمره و کدنویسی معرفی کند.

افزونهٔ VS Code جدید Vibe به‌صورت یک Panel کناری در کل پروژه کار
می‌کند و می‌تواند زمینه را از GitHub، GitLab، Jira یا Linear هم بخواند؛
CLI هم به‌روزرسانی شده تا Skillها را به‌صورت فرمان‌های Slash، حالت‌های
سفارشی، برنامه‌های قابل‌ویرایش، و پرسش چندگزینه‌ای میان‌کار پشتیبانی
کند.

  نمی‌دهد.

## چه زمانی و برای چه کسی کاربرد دارد؟

برای تیم‌هایی که از اکوسیستم Mistral استفاده می‌کنند و می‌خواهند یک
اشتراک واحد برای هم کارهای روزمرهٔ دفتری و هم کدنویسی عامل‌محور داشته
باشند، Vibe یک گزینهٔ یکپارچه‌شده است — به‌خصوص Code Mode برای تیم‌هایی
که به اجرای موازی و پس‌زمینه‌ای Pull Requestها علاقه دارند. اما پیش از
انتقال کامل، باید توجه داشت که این ارزیابی مستقل عملکرد کدنویسی Vibe
نسبت به Claude Code، Codex CLI یا Cursor وجود ندارد؛ انتخاب باید بر
اساس آزمایش مستقیم روی وظایف واقعی تیم باشد، نه فقط روی ادعاهای
بازاریابی مثل «تحویل کد قبل از جلسهٔ صبح».
